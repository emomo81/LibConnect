## 2025-01-31 - [Password Visibility Toggles]
**Learning:** Static HTML pages often lack basic interactivity like password toggles. Converting icon-only 'div' placeholders into accessible 'button' elements with dynamic 'aria-label' and icon updates significantly improves UX and accessibility.
**Action:** Always check for password fields in static sites and ensure they have functional, accessible visibility toggles using a consistent 'setupToggle' function.
